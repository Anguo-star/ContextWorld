# ContextWorld：Latent 世界模型的上下文学习基准

ContextWorld 评测 latent 世界模型能否从最近几步交互中识别隐藏的环境动力学，并据此
预测下一状态。模型在评测时不更新参数，也不能读取速度、动作延迟、物体质量、接触属性或
空间转移规则等模拟器隐藏变量。

评测直接在参评模型自己的 latent 空间中进行，不要求图像解码器或像素重建。因此，
JEPA、LeWM、PLDM、PreJEPA 以及其他 latent 世界模型可以使用同一套数据与评分协议。

## 1. Benchmark 概览

ContextWorld 包含九项任务，覆盖四类需要从历史中推断的动力学变化。任务按能力类型组织，
而不是按环境数量组织；九项任务分别计分，不计算跨任务平均分或统一总分。

| 能力类型 | 任务 | 环境 | 历史长度 | 模型需要判断什么 |
|---|---|---|---:|---|
| 即时连续响应 | 速度 | TwoRoom | 3 | 相同动作会移动多远 |
| 即时连续响应 | 推手移动幅度 | PushT | 3 | 相同动作会让推手移动较短还是较远 |
| 即时连续响应 | 机械臂质量 | Reacher | 3 | 质量如何改变机械臂对力矩的响应 |
| 时间延迟动力学 | 动作延迟 | TwoRoom | 7 | 动作等待多少步才生效 |
| 接触或附着条件动力学 | 接触摩擦 | PushT | 3 | 接触时摩擦如何改变运动 |
| 接触或附着条件动力学 | 运动阻尼 | PushT | 3 | 脱离接触后运动衰减得快还是慢 |
| 接触或附着条件动力学 | Cube 夹爪携带规则 | Cube | 3 | 闭合夹爪能否携带方块 |
| 隐藏结构转移 | 门通行规则 | TwoRoom | 3 | 外观相同的门能否通过 |
| 隐藏结构转移 | 传送门出口位置 | TwoRoom | 3 | 进入同一入口后会从哪里离开 |

TwoRoom 承载四项任务，但它们分别考察连续响应、时间延迟和结构转移。环境只是任务的
实现载体，不构成分数权重。

## 2. 数据与划分

`ContextWorld-v1` 是统一的数据分发包，包含九项任务的 Training 和 Development 数据、
任务注册表、组件说明及文件完整性清单。该数据包已在本地完成组装，但尚未公布稳定的
公共下载版本。

每项任务使用三种互不重叠的数据划分：

- **Training**：用于训练或适配模型；
- **Development**：用于实现检查、模型选择和消融实验；
- **Public Test**：用于最终结果报告，当前保持封存且不随数据包分发。

Public Test 不应用于反复调参。Development 结果必须明确标注划分，不能作为 Public Test
成绩报告。

| 任务 | Training | Development | Public Test | 主要变化范围 |
|---|---:|---:|---:|---|
| 速度 | 32 档速度 | 未见速度与诊断组合 | 每个参考速度 300 个查询 | 训练内插值与范围外速度 |
| 推手移动幅度 | 2,048 对 | 256 对 | 256 对 | 移动幅度 60 / 140 |
| 机械臂质量 | 2,048 对 | 256 对 | 256 对 | 密度 500 / 1500 |
| 动作延迟 | 延迟 0–10 | 独立查询 | 300 个查询 × 11 种延迟 | 0、1、2、3、4、5–10 六个响应组 |
| 接触摩擦 | 8,192 对 | 256 对 | 256 对 | 摩擦系数 0.05 / 0.80 |
| 运动阻尼 | 8,192 对 | 256 对 | 256 对 | 阻尼 0.2 / 1.0 |
| Cube 夹爪携带规则 | 2,048 对 | 256 对 | 256 对 | 可携带 / 不可携带 |
| 门通行规则 | 96 个门位置 | 16 个门位置 | 42 个未见门位置、300 个场景 | 可通过 / 被阻挡 |
| 传送门出口位置 | 2,048 对 | 256 对 | 256 对 | 靠近边界 / 远离边界的出口 |

配对任务让两个样本共享当前画面、查询动作和可观测状态，只改变历史中展示的隐藏规律。
真实未来由对应模拟器连续执行得到，不通过拼接不连续帧或直接修改标签构造。

## 3. 模型输入与输出

一个评测样本包含：

1. 最近若干帧真实图像；
2. 已经执行的动作序列；
3. 当前图像；
4. 接下来要执行的查询动作；
5. 每种候选隐藏规律对应的模拟器真实未来。

模型只能接收图像和动作。评分器不会提供隐藏参数、模拟器状态、奖励、价值函数或任务
标签。模型输出未来 latent；真实未来图像使用同一模型的冻结目标编码器编码，因此不同
模型不需要共享 latent 维度或数值尺度。

```text
历史图像 + 历史动作 + 当前图像 + 查询动作
                         │
                         ▼
                 参评模型预测未来 latent

每个候选真实未来图像 ──参评模型的冻结目标编码器──> 目标 latent
```

预测 latent 与各候选目标 latent 的距离用于判断模型选择了哪个真实未来。不同模型可以
比较同一任务上的正确率，但不能直接比较未经归一化的 raw latent loss。

## 4. 评测指标

### 4.1 上下文学习正确率

每个查询产生一个 0/1 结果：模型是否选择了与历史所示隐藏规律一致的真实未来。任务主
分数是查询正确率；部分任务还要求最弱条件、历史切换、方向一致性或 bootstrap 置信下界
同时达标。

| 任务 | 主分数要求 | 其他必要条件 |
|---|---:|---|
| 速度、门通行规则 | 按预先规定的方向判定 | 每个方向分别达标 |
| 推手移动幅度、接触摩擦、运动阻尼 | ≥ 95% | 历史使用与最弱条件达标 |
| 传送门出口位置 | ≥ 95% | 最弱出口 ≥ 90%，bootstrap 95% 下界 ≥ 90% |
| 动作延迟 | ≥ 75% | 最弱响应组 ≥ 60%，bootstrap 95% 下界 ≥ 70% |
| 机械臂质量、Cube 夹爪携带规则 | ≥ 75% | 历史切换与最弱条件达标 |

参考方法通常使用三个独立训练种子。只有三个检查点分别满足该任务的全部条件，方法才
记为 3/3 通过；平均分达到门槛不能替代逐检查点判定。

### 4.2 原任务规划能力

ICL 正确率回答“模型是否学会隐藏规律”，CEM 回答“模型原有的规划能力是否保持”。两项
结果分别报告，不合成一个分数。

标准 CEM 预算为六个评测种子（42–47），每个种子 50 次规划，共 300 次。历史结果若使用
同样的 300 次总预算但采用不同拆分，会在表中明确说明。训练后检查点与其对应的原始
检查点在相同查询上比较，并使用任务预先规定的最大允许下降。

### 4.3 结果比较

同一任务内的模型使用相同查询，可以直接比较正确率。若要声称一个方法优于另一个方法，
应对相同查询进行配对 bootstrap，并报告正确率差的 95% 置信区间。不同任务的分数不求
平均，不用于生成单一排行榜总分。

## 5. 参考结果

参考结果分为三层，分别回答不同问题：

1. **原始模型 ICL 起点**：只使用原环境数据训练的模型，在各能力任务上的零样本表现；
2. **原始环境 CEM 起点**：这些模型在原任务中的规划能力；
3. **组件训练后的结果**：模型是否学会目标规律，以及原任务规划能力是否保持。

三层结果不能互相替代。表中的 Public Test 数值来自已经完成并记录的参考评测；测试数据
本身仍保持封存。

### 5.1 原始 LeWM 与 PLDM 的 ICL 起点

下表使用每个原始环境的一枚 LeWM 和一枚 PLDM 检查点。这些检查点按公开原始数据和统一
基线配方训练 10 epochs，未使用任何 ContextWorld 组件训练数据。结果用于描述起点，不
代表训练后方法已经解决相应任务。

| 任务 | 评测划分 | LeWM | PLDM |
|---|---|---:|---:|
| 速度 | Public Test | 59.33% | 51.44% |
| 推手移动幅度 | Public Test | 49.80% | 43.55% |
| 机械臂质量 | Public Test | 50.00% | 52.93% |
| 动作延迟 | Public Test，使用 History=7 的末尾三帧 | 16.67% | 16.67% |
| 接触摩擦 | Development | 49.61% | 50.00% |
| 运动阻尼 | Development | 50.00% | 50.39% |
| Cube 夹爪携带规则 | Public Test | 50.98% | 50.98% |
| 门通行规则 | Public Test | 50.00% | 50.00% |
| 传送门出口位置 | Public Test | 50.00% | 50.20% |

动作延迟的原始检查点只支持 History=3，因此 16.67% 是把评分历史中对齐的最后三帧交给

### 5.2 原始环境 CEM 起点

每行报告同一训练配方三个独立训练种子的平均成功率和样本标准差。每个检查点均完成
300 次规划评测。

| 原始环境 | LeWM | PLDM | DINO-WM / PreJEPA |

| TwoRoom | 92.44% ± 0.51pp | 90.56% ± 5.17pp | 98.44% ± 1.02pp |

| Cube | 65.44% ± 0.69pp | 53.44% ± 1.07pp | 73.33% ± 1.20pp |

## 6. 任务说明

每张任务卡使用相同的五部分结构，便于读者横向比较任务目标、数据、指标、参考结果与
结论范围。

### 6.1 即时连续响应

#### 6.1.1 速度

##### 任务目标

模型根据近期移动判断当前速度，并预测同一动作对应的下一状态。

##### 数据构成

Training 覆盖 32 档速度。评测分别包含训练中出现的速度、训练范围内未见速度，以及低于
和高于训练范围的速度。

##### 评测方法

主指标是训练范围内未见速度的一步严格正确率：与真实速度一致的历史必须同时优于另外
两档历史。若要把提升归因于多速度训练，还需要同训练种子的单速度对照。

##### 基线表现

原始 LeWM 和 PLDM 分别为 59.33% 和 51.44%。训练后 LeWM 平均 95.26%；PLDM 三个检查点
为 97.22%、96.44% 和 96.44%，平均 96.70%。两者都通过训练范围内插值，但高、低范围外
结果均未通过。PLDM 原任务 CEM 平均 94.78%；另一个 action-planning 分析平均 69.56%，
后者没有预设性能门槛。

##### 适用范围

结果支持 History=3 下的训练内插值，不代表任意速度外推。PLDM 缺少同训练种子的单速度
对照，因此不能把观察到的变化归因于多速度数据本身。

#### 6.1.2 推手移动幅度

##### 任务目标

模型判断相同二维动作会让 PushT 推手移动较短还是较远。两档参数为 60 和 140。

##### 数据构成

Training 包含 2,048 对场景，Development 和 Public Test 各包含 256 对。配对查询共享当前
状态、画面和动作。

##### 评测方法

主指标是真实下一状态选择正确率，同时检查模型是否使用正确历史、是否随历史切换预测，
以及最弱幅度条件是否达标。通过门槛为每个检查点至少 95%。

##### 基线表现

原始 LeWM 和 PLDM 分别为 49.80% 和 43.55%。训练后 LeWM 平均 96.61%，3/3 通过且保持
原 PushT 规划能力；PLDM 平均 94.27%，三个检查点均低于 95% 门槛。

##### 适用范围

任务验证二值动作响应，不验证连续幅度估计或范围外外推。

#### 6.1.3 机械臂质量

##### 任务目标

模型根据相同力矩下的近期运动判断 Reacher 机械臂较轻还是较重。两档密度为 500 和
1500。

##### 数据构成

Training 包含 2,048 对场景，Development 和 Public Test 各包含 256 对。任务改变主体连杆
和末端球的质量，保持第二连杆不变。

##### 评测方法

主指标是真实下一状态选择正确率，并检查历史切换、最弱质量条件、bootstrap 置信下界和
latent 响应。三个训练种子必须分别达到 75%。

##### 基线表现

原始 LeWM 和 PLDM 分别为 50.00% 和 52.93%。训练后 LeWM 平均 76.11%，3/3 通过并保持
原 Reacher 规划能力；PLDM 平均 63.15%，未通过。

##### 适用范围

任务验证两档质量的一步适应，不验证连续质量估计、范围外外推或多步闭环控制。

### 6.2 时间延迟动力学

#### 6.2.1 动作延迟

##### 任务目标

模型使用七帧历史判断动作等待多少步才生效，并预测下一步真实物理响应。

##### 数据构成

延迟范围为 0–10。Training 先覆盖差异明显的 0、4、8，再覆盖完整范围；Public Test 包含
300 个查询，每个查询保存 11 种延迟的真实轨迹。

##### 评测方法

延迟按真实下一步响应分为 0、1、2、3、4 和 5–10 六组，各组在每个查询内等权。总体
正确率须至少 75%，最弱组至少 60%，bootstrap 95% 下界至少 70%。

##### 基线表现

原始 History=3 LeWM 和 PLDM 在末尾三帧投影下均为 16.67%。训练后 PLDM 平均 93.36%，
3/3 通过；LeWM 平均 32.43%，未通过。两者的训练后原任务 CEM 均保持。

##### 适用范围

结果验证 History=7 下的一步延迟响应，不验证未见延迟外推、多步自回归或隐藏延迟下的
闭环规划。

### 6.3 接触或附着条件动力学

#### 6.3.1 接触摩擦

##### 任务目标

模型根据推手与物体接触时的响应判断摩擦较小还是较大。两档摩擦系数为 0.05 和 0.80。

##### 数据构成

Training 包含 8,192 对样本，Development 和 Public Test 各包含 256 对。配对查询的当前
完整物理状态误差不超过 `1e-5`，不同划分不共享查询或生成模板。

##### 评测方法

主指标是真实下一状态选择正确率，同时检查正确历史、预测切换和最弱摩擦条件。当前参考
方法未满足 Development 的全部条件，因此没有读取 Public Test。

##### 基线表现

原始 LeWM 和 PLDM 的 Development 起点为 49.61% 和 50.00%。当前训练后 LeWM 为 96.09%，
但未满足全部开发阶段条件；PLDM 为 52.73%。两者均没有 Public Test 或训练后 CEM 结果。

##### 适用范围

数据和评分器可用于评测新模型；现有结果不能说明 LeWM 或 PLDM 已稳定学会接触摩擦。

#### 6.3.2 运动阻尼

##### 任务目标

模型根据接触结束后的运动判断物体减速较快还是较慢。两档阻尼为 0.2 和 1.0。

##### 数据构成

Training 包含 8,192 对样本，Development 和 Public Test 各包含 256 对。配对样本交换起点，
使仅凭起点预测标签的准确率为 50%。

##### 评测方法

主指标是真实下一状态选择正确率，同时检查正确历史、预测切换和最弱阻尼条件。当前参考
方法未满足 Development 的全部条件，因此没有读取 Public Test。

##### 基线表现

原始 LeWM 和 PLDM 的 Development 起点为 50.00% 和 50.39%。当前训练后 LeWM 为 97.46%，
但未满足全部开发阶段条件；PLDM 为 51.95%。两者均没有 Public Test 或训练后 CEM 结果。

##### 适用范围

数据和评分器可用于评测新模型；现有结果不能说明 LeWM 或 PLDM 已稳定学会运动阻尼。

#### 6.3.3 Cube 夹爪携带规则

##### 任务目标

模型根据夹爪与方块的近期响应判断闭合夹爪能否携带方块，并预测共享查询动作对应的真实
下一状态。

##### 数据构成

Training 包含 2,048 对，Development 和 Public Test 各包含 256 对。四类动作模板在每个划分中严格均衡；源轨迹、动作模板、场景、配对内容和 query 画面互不重叠。

##### 评测方法

每个检查点的真实未来正确率至少为 75%，正确历史至少 75%，上下文切换至少 90%，最弱
规则至少 70%。通过 Development 的模型还需完成 300 次原 Cube CEM。外部模型使用独立结果身份，不会覆盖仓库提供的参考结果。

##### 基线表现

原始 LeWM 和 PLDM 均为 50.98%。训练后 LeWM 三个 Public Test 结果为 77.73%、79.10% 和 78.52%，全部通过；CEM 为 186、183、185/300，均在允许范围内。PLDM 在 Development
为 50.13%，未通过。

##### 适用范围

结果验证二值携带规则的一步 ICL 和原 Cube 规划能力保持，不验证连续夹持强度或多步闭环
适应。公开分发仍须补齐许可证和稳定下载地址。

### 6.4 隐藏结构转移规则

#### 6.4.1 门通行规则

##### 任务目标

模型根据历史中的穿门或碰壁结果判断外观相同的门能否通过。

##### 数据构成

Training 覆盖 96 个门位置，Development 覆盖 16 个门位置，Public Test 使用 42 个训练中
未见的门位置并包含 300 个场景。

##### 评测方法

每个查询保存“可通过”和“被阻挡”两种模拟器真实未来。评分分别检查两个穿门方向、历史
是否改变判断，以及两种未来在 latent 中是否可分。

##### 基线表现

原始 LeWM 和 PLDM 均为 50.00%。训练后两者分别达到 100.00% 和 99.33%，均通过 ICL；
但训练后 CEM 明显下降，均未保持原 TwoRoom 规划能力。

##### 适用范围

任务验证一步门规则判断，不验证多步闭环穿门规划。

#### 6.4.2 传送门出口位置

##### 任务目标

模型根据历史中的传送结果判断进入同一入口后会从靠近边界还是远离边界的位置出现。

##### 数据构成

Training 包含 2,048 对场景，Development 和 Public Test 各包含 256 对。两种规律在查询前
汇合到相同当前状态，因此当前画面和动作本身不能泄露答案。

##### 评测方法

主指标是真实出口下一状态选择正确率，并检查正确历史、预测切换、最弱出口条件、
bootstrap 置信下界和 latent 响应。三个训练种子必须分别满足完整标准。

##### 基线表现

原始 LeWM 和 PLDM 分别为 50.00% 和 50.20%。训练后 LeWM 平均 83.92%，PLDM 平均
59.31%，均未满足完整 ICL 标准；LeWM 保持原 TwoRoom 规划能力。

##### 适用范围

任务验证二值出口规则的一步适应，不验证连续出口坐标、范围外出口或多步传送规划。

## 7. 接入新的 latent 世界模型

外部模型实现
`contextworld.benchmarks.adapters.LatentWorldModelAdapter` 即可使用统一评分器，不需要为
九项任务分别实现一套接口。Adapter 提供：

- `encode_pixels`：用模型的冻结目标编码器编码真实未来图像；
- `rollout_latents`：根据历史图像、历史动作、当前图像和查询动作预测未来 latent；
- `protocol`：声明历史长度、动作块、动作维度和预测步数；
- `metadata` 与 `frozen_state_hash()`：记录模型身份，并确认评测没有改变模型权重。

评分器只检查历史长度、每个动作块的原始步数、动作维度和预测 horizon。它不限制 latent
维度、网络结构、深度学习框架或训练数据加载方式。

```bash
pip install -e ".[eval]"
export CONTEXTWORLD_BENCHMARK_ROOT=/path/to/ContextWorld-v1

python -m contextworld.benchmarks.external_model_cli \
  --benchmark-root "$CONTEXTWORLD_BENCHMARK_ROOT" \
  --evaluation-split development \
  --task speed \
  --adapter your_package.module:YourAdapter \
  --checkpoint /path/to/checkpoint \
  --model-name your-model \
  --output /path/to/result.json
```

完整接口、数组形状和模型加载方式见
[外部模型 Adapter 规范](External_Model_Adapter_Contract.md)。

## 8. 可复现性与结果报告

公开 Training 与 Development 工作流只需要 `ContextWorld-v1`。原始模型训练和 CEM 还需要
相应的原环境数据，不依赖数据生成、训练日志或历史实验所在的研究工作目录。

建议每项结果至少报告：

- 模型名称、参数量和检查点标识；
- 训练数据、训练种子和优化预算；
- Adapter 版本与输入协议；
- 评测划分；
- 主分数、附加条件和逐训练种子结果；
- 若模型支持规划，训练前后的原任务 CEM；
- 未运行或不能评分的项目及明确原因。

机器可读结果可通过 `contextworld-benchmark results` 查看。已经报告的参考结果还提供训练
配方、检查点哈希和逐次评测记录，详见
[结果复现附录](reference/Benchmark_Result_Provenance.md)。历史实验协议位于
`docs/protocols/`，用于复核结果，不是运行公开数据包的前置要求。

## 9. 适用范围与限制

ContextWorld 的结论仅覆盖本文列出的环境、隐藏规律、历史长度和参数范围。当前结果不能
证明：

- 一个模型能够同时解决全部九项任务；
- 模型能够处理多种隐藏规律同时变化；
- 模型能够外推到任意未见参数；
- 一步预测能力必然转化为所有任务上的闭环规划能力；
- 仓库内参考模型已经代表所有 latent 世界模型架构。

Public Test 保持封存，不应用于模型选择。公开发布仍需提供稳定的数据集修订版本、最终
分发元数据和计划中的独立模型验证。
