# TwoRoom 可见门位置泛化报告

**更新日期**：2026-07-22

**当前状态**：Validation 全矩阵已完成；预注册预测判定未通过；正式 Test 未运行并继续锁定

**机器配置**：[`tworoom_door_visual_generalization_v1.yaml`](../configs/benchmark/tworoom_door_visual_generalization_v1.yaml)

## 1. 阶段结论

本轮没有通过“多门位置训练在每个 Validation 门位置都优于固定门位置训练”的预注册
标准，因此不能写成总体可见门位置泛化已经正式成立，正式 Test 也没有解锁。

结果并不是“多门位置训练无效”。在训练范围内但训练未见的门位置 53、85、117、149
上，多门位置模型的一步穿门预测和撞墙预测，在三个训练种子、全部门位置和全部 Eval
seed 分区上都优于配对的固定门模型。固定候选动作评测也显示明显的终点误差、动作排序
和穿门率收益。正式判定失败，只因为固定门模型专门训练的门位置 49 上，多门模型略差
约 0.0007～0.0021 个标准化误差单位，而冻结规则要求每个门都必须严格更好。

| 证据 | 训练见过的门位置 | 训练范围内的新门位置 | 阶段判断 |
|---|---|---|---|
| 一步真实未来预测 | 两个任务均未通过逐门严格门槛 | 两个任务均通过 | 总体未通过 |
| 连续通过 horizon | 0 | 1 个 action block | 长期撞墙预测仍不稳定 |
| 固定候选动作 | 三种子整体均明显改善 | 三种子整体均明显改善 | 强支持证据，不改变主门结论 |
| CEM 闭环规划 | 三种子整体稳定改善 | 跨种子和指标不稳定 | 支持已见门规划，不支持稳定插值规划 |
| 原始能力保持 | 多门配方 3/3；固定门配方 2/3 | 不适用 | 多门配方保持原始能力 |
| 正式 Test | 未运行 | 未运行 | 继续锁定 |

这里测的是当前画面中可见门结构的视觉泛化，不是门位置 ICL。门的位置已经画在 query
里，模型不需要通过历史交互猜门在哪里。

## 2. 实验测什么

实验比较三个模型组：

| 模型 | 训练数据 | 在本实验中的作用 |
|---|---|---|
| 原始数据模型 | 只用原始 TwoRoom 数据 | 单种子描述性参照 |
| 固定门位置合成混训模型 | 原始数据 50% + 门始终位于 49 的合成数据 50% | 控制额外数据量和训练流程 |
| 多门位置合成混训模型 | 原始数据 50% + 16 个门位置的合成数据 50% | 检验门位置多样性带来的收益 |

正式训练归因只比较同一训练种子的固定门模型和多门模型。训练种子为 3072、4096、
5120；原始数据模型只有一个种子，不进入配对判定。

评测分四层：

1. 用冻结的真实未来画面检查模型预测，而不是只看最终目标代价；
2. 给所有模型完全相同的 300 条候选动作，检查动作排序；
3. 用同一套 CEM 配置运行闭环跨房间规划；
4. 回到原始 episode-heldout 任务，检查新训练是否破坏原始能力。

正常连续三帧是正式输入。只给当前画面会改变训练时的序列长度，只作为诊断项，不参与
主门槛。

### 3.3 Validation 样本

| Validation 轨道 | 门位置 | 与多门训练集的关系 |
|---|---|---|
| 训练见过的门位置 | 49、89、129、169 | 训练值 |
| 训练范围内的新门位置 | 53、85、117、149 | 位于训练范围内，但不是训练值 |

每个门位置、每个任务都有 6 个 Eval seed（42～47），每个 seed 有 50 个不同 query，
即独立的 `50×6=300`。穿门预测和撞墙预测各自完整运行 300 条，不平分样本。

每个 checkpoint 的离线预测规模为：

```text
8 个门 × 2 个任务 × 2 种输入 × 300 = 9,600 条预测序列
9,600 × 4 个 horizon = 38,400 个 loss
```

7 个 checkpoint 共得到 67,200 条序列和 268,800 个 horizon loss。评分过程中不在线
调用环境，不使用 teacher forcing；所有模型复用相同 query、动作和真实未来。

## 4. 主证据：真实未来预测

### 4.1 指标怎样理解

对同一 checkpoint，先用它自己的冻结 encoder 编码真实未来，再计算预测 latent 的 MSE。
跨模型比较使用相对静止画面的误差倍数：

```text
标准化误差 = 模型预测真实未来的 MSE
             ÷ 把 query 画面原样当作未来的 MSE
```

数值越低越好。它不是准确率，也不转换成百分数。不同 checkpoint 的原始 latent 空间
不同，因此禁止直接比较跨 checkpoint 的原始 MSE。

下表使用配对差值：

```text
Δ = 固定门位置模型标准化误差 − 多门位置模型标准化误差
```

正数表示多门模型更好。`正分区`统计 4 个门 × 6 个 Eval seed 中方向为正的格数；冻结
门槛要求三个训练种子在两个任务上都达到 24/24。

### 4.2 正常连续三帧的一步结果

| Validation 轨道 | 任务 | 种子 3072：Δ / 正分区 | 种子 4096 | 种子 5120 | 正式判断 |
|---|---|---:|---:|---:|---|
| 训练见过 | 穿门预测 | +2.197 / 18/24 | +3.750 / 18/24 | +4.003 / 18/24 | 未通过 |
| 训练见过 | 撞墙预测 | +0.345 / 18/24 | +0.929 / 18/24 | +0.760 / 18/24 | 未通过 |
| 范围内新门 | 穿门预测 | +2.340 / 24/24 | +4.620 / 24/24 | +4.065 / 24/24 | 通过 |
| 范围内新门 | 撞墙预测 | +0.414 / 24/24 | +1.036 / 24/24 | +0.927 / 24/24 | 通过 |

范围内新门的一步结果包含 7,200 个配对 query；多门模型在 7,200/7,200 条上误差更低。

训练见过轨道的 18/24 不是随机分散的失败。门 89、129、169 的所有分区都为正，六个
失败分区全部来自门 49。门 49 的逐门差值如下：

| 训练种子 | 穿门预测 Δ | 撞墙预测 Δ |
|---:|---:|---:|
| 3072 | −0.001986 | −0.000678 |
| 4096 | −0.001223 | −0.002028 |
| 5120 | −0.001011 | −0.002073 |

跨门平均虽然明显有利于多门模型，但预注册禁止用其他门的较大收益掩盖单门失败，所以
总体门槛仍判为未通过。

## 5. 支持证据

### 5.1 固定候选动作

固定候选 Validation 完整运行了 7 个模型 × 8 个门 × 6 个 Eval seed，共 336 个结果
文件和 16,800 条 query 记录。每个 query 使用同一组 300 条冻结候选动作。终点遗憾
越低越好；动作排序是处理并列值后的 Spearman 相关，越高越好；穿门率越高越好。

下表为三个配对训练种子的平均值：

| Validation 轨道 | 终点遗憾：多门 / 固定（px） | 动作排序：多门 / 固定 | 穿门率：多门 / 固定 |
|---|---:|---:|---:|
| 训练见过 | 0.384 / 69.858 | 0.481 / 0.238 | 99.69% / 32.86% |
| 范围内新门 | 14.451 / 67.680 | 0.313 / 0.258 | 86.03% / 31.22% |

三个训练种子在两个轨道的三项整体指标上方向一致。但它仍不是“每个门都更好”：门 49
近似持平；与 49 相邻的插值门 53 偏向固定门模型；门 85 的动作排序只有一个种子为正。
门 89、117、129、149、169 的三个种子和三项指标均支持多门模型。

固定候选结果证明门位置多样性显著改变了动作排序，但它是规划层支持证据，不能覆盖已
失败的真实未来主门槛。

### 5.2 CEM 闭环规划

正式 CEM Validation 完整运行了 7 个模型 × 8 个门 × 6 个 Eval seed，共 336 个结果
文件和 16,800 条闭环记录。每个文件有 50 个独立 query；冻结配置为 100 步执行预算、
10 个 action block 规划视野、300 个候选、30 轮优化和 top-k 30。

下表为三个配对训练种子的等权平均。到达步数只比较两个模型都成功的 query；差值均为
“多门模型 − 固定门模型”。成功率和穿门率的正数有利，最终距离和步数的负数有利。

| Validation 轨道 | 成功率：多门 / 固定 / Δ | 最终距离：多门 / 固定 / Δ（px） | 穿门率：多门 / 固定 / Δ | 共同成功步数 Δ |
|---|---:|---:|---:|---:|
| 训练见过 | 51.22% / 19.92% / +31.31 点 | 72.71 / 86.06 / −13.35 | 58.03% / 31.61% / +26.42 点 | −7.84 |
| 范围内新门 | 22.31% / 13.06% / +9.25 点 | 96.25 / 86.67 / +9.58 | 28.67% / 27.44% / +1.22 点 | +0.32 |

训练见过轨道上，三个训练种子的四项分布均值方向全部支持多门模型。范围内新门则不
稳定：种子 3072 的四项指标全部变差，种子 4096 全部改善，种子 5120 只有成功率和
共同成功步数改善。三种子平均后虽然成功率提高，但最终距离变差，穿门率和到达步数
近似持平。

逐门结果也说明成功率不能单独代表整条规划更好。门 117 的三个种子都更常成功和穿门，
但最终距离和共同成功步数多数变差；门 53 仍表现出固定门模型的局部优势。准确结论是：
多门训练显著改善了已见门位置的闭环规划，但还没有把固定候选层的强插值收益稳定转化
为未见中间门位置的完整闭环收益。剩余问题可能来自 CEM 搜索、长程自回归预测或两者
共同作用，不能仅凭本轮结果进一步归因。

### 5.3 原始能力保持

原始 episode-heldout 能力保持共运行 42 个 planning 文件和 7 个多步 rollout 文件。
每个模型的 planning 仍是独立 `50×6=300`。原始数据模型在相同 300 个 query 上的
成功率为 91.00%，平均最终距离为 19.91 px。

下表中差值为“候选模型 − 原始数据模型”。成功率差越高越好，最终距离差越低越好。

| 模型 | 成功率 | 成功率差及 95% CI（百分点） | 最终距离（px） | 距离差及 95% CI（px） | 判定 |
|---|---:|---:|---:|---:|---|
| 固定门，种子 3072 | 92.33% | +1.33 [−1.67, +4.33] | 19.20 | −0.71 [−2.60, +1.22] | 通过 |
| 固定门，种子 4096 | 87.33% | −3.67 [−6.67, −0.67] | 22.67 | +2.77 [+0.72, +4.94] | 未通过 |
| 固定门，种子 5120 | 91.33% | +0.33 [−3.00, +3.33] | 20.13 | +0.22 [−2.11, +2.55] | 通过 |
| 多门，种子 3072 | 97.00% | +6.00 [+3.33, +9.00] | 16.32 | −3.59 [−5.91, −1.50] | 通过 |
| 多门，种子 4096 | 96.33% | +5.33 [+2.67, +8.33] | 16.70 | −3.21 [−5.46, −1.22] | 通过 |
| 多门，种子 5120 | 98.67% | +7.67 [+5.00, +10.67] | 14.90 | −5.01 [−7.27, −2.92] | 通过 |

非劣门槛要求成功率差的置信下界不低于 −5 个百分点、最终距离差的置信上界不超过
+5 px，并且原本可解决的任务分层不能整体失效。固定门种子 4096 只因成功率置信下界
为 −6.67 点而失败，所以固定门配方的组判断为 2/3、未稳定保持。多门配方为 3/3；
三个种子不仅非劣，而且成功率和最终距离都稳定优于原始参照。

多步 rollout 还显示每个模型自身的误差都会随 H1、H2、H3、H5 单调累积，H5 原始
latent MSE 是 H1 的约 4.63～6.50 倍。不同 checkpoint 的 latent 空间不同，不能用这些
跨模型原始 MSE 排名；它们只描述长程误差增长，也不参与能力保持硬门槛。

机器汇总中的顶层 `status: passed` 只表示 7 模型矩阵、67,200 条预测序列和所有哈希
审计完整。真正的能力判定字段是：

```text
decision.visible_geometry_generalization_validation_gate_passed = false
```

独立从原始记录重算所有 gate 单元，与正式汇总的最大差异为 0；配置、catalog、
checkpoint、normalizer 和结果文件共 19/19 组哈希一致。因此这不是符号或聚合错误。

sealed-Test manifest 保持 `locked_pending_validation`，冻结记录保持 `pending_validation`。
正式 Test 没有生成或评分，也不能为了诊断 Validation 失败而打开。

## 7. 能说什么，不能说什么

当前证据支持：

- 多门位置训练带来了很强的一步、范围内新门位置预测收益；
- 收益同时出现在穿门和撞墙任务，并跨三个训练种子稳定；
- 穿门预测收益可延续到 H5；
- 固定候选动作的终点误差、排序和穿门率显著改善。

当前证据不支持：

- 预注册的总体可见门位置泛化判定已经通过；
- 多门模型在每个门位置都严格优于固定门模型；
- 长期撞墙预测已经稳定；
- 范围外门位置外推或 sealed Test 结论；
- 门位置 ICL。门在当前 query 画面中可见。

原始数据模型只有一个训练种子，只能描述，不能代替配对控制组做正式归因。

## 8. 下一步

v1 Test 必须保持锁定。下一步应先在 Validation 范围内完成失败分解，重点检查两个边界：

1. 多门模型在固定门基准点 49 的微小损失，是容量分配、采样配比还是冻结判据把“近似
   持平”当成失败；
2. 撞墙预测在 H2 以后快速累积误差，是否需要更强的碰撞轨迹覆盖或多步训练目标。

如果据此改变训练配方或判定方式，应注册新的 v2 和新的 Validation 划分，不能回头修改
v1 门槛。可见几何基础确认后，能力路线仍按以下顺序推进：

```text
可见门几何基础 → 隐藏通道规则 ICL → 速度 ICL × 可见门位置组合
```

隐藏通道规则将让当前 query 无法判断哪条通道可通过，必须根据 History-3 的碰撞或通过
结果判断。这才是门相关 ICL。
