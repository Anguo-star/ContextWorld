<a id="rollout-error-diagnostic"></a>

## 端点误差与真实观测替换

各任务折叠表比较同一检查点、场景和动作下的**自由推演**与**真实观测替换**。前者把预测反馈为后续输入；后者每次预测前只提供截至该时刻的真实历史，不提供尚未发生的未来。替换分支仅用于定位误差，不计入自由推演的 E/B。

第 5、25 个物理步的端点误差均除以该检查点在五个评分时刻上的**整段参照平均能量 B**，并非分别以端点能量归一化。因此可在同一行比较误差随递推的变化，但端点读数不能直接等同于整段 E/B。表中的差值为自由推演误差减真实输入误差，允许正负；替换同时纠正当前状态并刷新历史中的动力学证据，不是可相加的因果误差占比。


<a id="九任务明细"></a>

## 九任务明细

**每项任务先给一张核心对比表**，展示同一模型各训练方案的主指标、History、响应 NRE、多步 E/B 和 CEM。更详细的响应指标、Speed 分布以及自由／真实输入对照折叠保留。数据、训练与评分定义分别见 §2、§5.1、§4。

主指标、History 与 CEM 为百分数，NRE 与 E/B 为无量纲误差比，越低越好。NRE 使用原查询及其原分组，多步 E/B 使用扩展候选与第 5–25 物理步，**二者不是同一面板的同一个误差**。`±` 表示训练重复标准差；`[95% 区间]` 表示固定检查点下的场景 bootstrap 区间。`n (任务/多步/CEM)` 分别列三种测量的训练重复数，不是查询数；只有一次训练不写零标准差。

`—` 为没有可比结果，不填零。Delay 的 T0† 是 H3 投影参考，不混入 H7 多步统计。Speed 核心表用未见插值，完整表另列其他分布；History 与 Speed 主指标相同。响应 Gain、Switch、Joint 等完整定义见 §4.2。

### 6.1 即时连续响应

<a id="task-speed"></a>

#### 6.1.1 速度

### 6.2 时间延迟动力学

<a id="task-action-delay"></a>

#### 6.2.1 动作延迟

**任务目标。** 模型使用七帧历史判断动作等待多少步才生效，并预测下一步真实物理响应。

**数据构成。** 延迟范围为 0–10。Training 覆盖完整范围；Public Test 包含
300 个查询，每个查询保存 11 种延迟的真实轨迹。

**任务主指标。** 动作延迟有两个不同强度的评测问题，回答的研究问题不同，不能互相替代：

- **六组物理响应识别（正式指标）**：延迟按真实下一步响应分为 0、1、2、3、4 和 5–10 六组，
  各组在每个查询内等权宏平均，并报告最弱组表现。该指标判断模型是否区分六组一步响应，不区分 5–10 组内的延迟值。
- **二元历史响应诊断**：只判断预测在 delay=0 与 delay≠0（合并为一类）之间是否随历史
  正确切换，不要求区分不同的非零延迟。这是判断“历史是否引起了正确方向的条件差异”
  的更弱标准，主要用于快速诊断。

**解释范围。** 正式结果衡量 History=7 下六个一步物理响应组（0、1、2、3、4、5–10）的识别能力。
一步未来无法区分 5–10，因此不表示精确识别全部 11 档延迟；两步、三步未来（h2/h3）是辅助诊断，
不计入主分。也不验证未见延迟外推、多步自回归或隐藏延迟下的闭环规划。二元诊断数值只说明
“有无延迟”的区分，不能单独支撑延迟识别结论。

`†` 表示 T0 仅使用 H3 输入适配，该行不能与原生 H7 模型作同架构训练增益比较；“仅 CEM”表示该配置只有原环境规划结果。

**多步评测。** 300 个场景、11 档延迟，使用七帧真实历史。各延迟等权，按五个时刻的完整未来评分；该版本不沿用原一步评分的六组宏平均，因为多步后果可以区分更多延迟。
