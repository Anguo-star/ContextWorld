# ContextWorld 参考结果复现附录（v3）

本附录记录当前冻结参考的身份、覆盖范围、复现入口和限制。历史实验与未冻结的中间记录已移至
[Pre-V3 编辑归档](../archive/Benchmark_Result_Provenance_Pre_V3_Editorial.md)，不与当前
参考结果混合比较。

## 1. 当前冻结身份

当前参考使用 `joint_scratch_v1`（`CW_METHOD=native`、从零训练、10 epochs、训练种子
3072/3073/3074）。LeWM、PLDM 和 DINO-WM 覆盖九项 ContextWorld 组件；逐检查点主分数、
门槛合取、训练源码哈希与数据身份由
[`contextworld_joint_scratch_v1_reference_results_freeze_v3.json`](../../configs/benchmark/contextworld_joint_scratch_v1_reference_results_freeze_v3.json)
冻结。主文档表格默认报告 Public Test；接触摩擦和运动阻尼因当前 Development 未通过准入，保留
Development 数值并明确标注。

冻结文件 SHA-256：`01298ca407c4a72bdd9a1238879ae7109b1141a7cfdd2b25065cb0bdec87fef0`。
验收结论及机器可读证据见 [固定研究基准最终验收](Baseline_Final_Acceptance_2026-09-10.md)。

Development 与 Public Test 使用隔离数据行。Development 用于实现检查、配方选择和门槛准入，
Test 只用于最终离线报告。DINO-WM 原始 predictor 需要 `observation`/`proprio`，不兼容
RGB+动作的 ICL 接口，因此原始 ICL 记为“—”；其 CEM 是补充证据。

## 2. 复现入口与评分合同

训练入口为 `scripts/run_stablewm_train.py`，训练配置为
`configs/training/stablewm_family_profiles_v1.yaml`。机器可读冻结记录是唯一当前数值来源；
主文档的数字核对由 `tests/test_public_document_numbers_match_frozen_results.py` 完成。

当前 ICL 主指标按组件定义：速度使用参考速度严格胜率，动作延迟使用六个物理响应组宏平均，
门通行使用规则与方向分层选择率，其余组件使用配对未来选择率。门槛还检查最弱条件、历史
切换、latent 响应与适用的 bootstrap 下界。CEM 每个检查点使用评测种子 42–47、每种子 50
次，共 300 次；CEM 与 ICL 分开报告，不从两列直接推出非劣性结论。

冻结覆盖 81 个组件训练单元、54 个原始环境基线单元，共 135 个检查点/任务单元；Development
与 Public Test 各 135 份原始结果，共 270 份。复核应使用冻结记录中绑定的训练身份，不以当前可变训练配置
重新声称复现基线。常用检查命令为：

```bash
python scripts/freeze_current_reference_baseline.py verify
python scripts/render_current_reference_tables.py --check
python scripts/verify_reference_capability_controls.py
```

以上命令从仓库根目录运行：分别检查冻结工件及数据绑定、主表与 Development 表、固定
正/负控制。判定内核为 `contextworld.benchmarks.reference_decision`，合同 ID 为
`contextworld_reference_decision_v2`。原始大结果与数据不全随 Git 分发；跨机器复核须同时
提供冻结记录引用的本地工件。

## 3. 当前参考的能力边界

速度结果支持训练范围内插值，不能外推到范围外速度。动作延迟的正式结果识别六个物理响应组，
不等价于精确区分全部 11 个延迟值，也不验证多步闭环。接触摩擦和运动阻尼当前只形成
Development 失败证据；存在历史 Test 工件不改变其当前准入状态。门通行主分数接近饱和，
应同时读取门槛输入。传送门、推手幅度及其他未通过组件的结果不能据此宣称任务不可学习。

CEM 相对变化是描述性证据；正式非劣性声明必须引用同一查询、逐种子配对分析和预注册允许
下降。不同训练配方、初始化、数据几何或代码版本之间的分数差异不能归因于单一因素。DINO
不兼容原始 RGB+动作 ICL 接口的限制仍然有效。

## 4. 来源证据与复现限制

v3 绑定 48 个评测源码文件，并验证实际评测数据字节及选择合同。六项配对任务的 Test
结果共 90 个绑定，对应 6 张实际表、18 个文件；数据身份以冻结记录及其引用工件为准。

255 份历史结果没有自动记录的运行时指纹；检查点 SHA 保留评测时声明，本次验收未重读
全部权重。部分早期 native manifest/provenance 未保留，当前表通过实际字节、发布表哈希
与结果绑定的外层包 manifest 核对。这些证据支持固定内部对照，不能声称已在干净环境中
完整重现所有历史运行。DINO-WM 的 CEM 与组件结果继续保留既有补充证据身份。
